> **Ранняя dev-версия.** Это proof of concept, а не готовый мод. Возможны вылеты, глюки графики и
> недостающие функции. Файлов игры в репозитории нет, нужна своя копия игры.
> Проект не связан с Hasbro, High Moon Studios и Activision.

Кампания Fall of Cybertron одиночная, а официальные онлайн-сервисы игры не работают. Этот проект добавляет
кооператив поверх штатной репликации Unreal Engine 3 по обычному TCP с прямым IP-адресом.
Это прокси `dinput8.dll`, который загружает игра, и небольшой лаунчер.

Поддерживаемый билд: Steam, `TFOC.exe` SHA-256
`c1dab177f81503ecb831d63a3d799f928dd9823242ca3689482c684396acfedc`.

## Статус

| Функция | Состояние |
|---|---|
| Escalation, 2 игрока (проверена карта Ark) | Работает |
| Кампания, глава 1 «The Exodus», 2 игрока | Работает, гостя выручает rescue-телепорт |
| Подключение по прямому IP (без онлайн-сервисов) | Работает |
| Лаунчер (установка, хост, подключение) | Работает |
| Несколько копий игры на одном ПК | Работает |
| Кампания, главы 2-9 | Не проверено |
| 3-5 игроков | Не проверено |
| Игра через интернет | Не решено (только LAN, localhost или VPN) |
| Режимы версуса, кроме Escalation | Не пробовалось |
| Установщик | Нет |

### Известные проблемы

- У гостя персонажи выглядят как тёмные силуэты или с тёмными текстурами.
- Гость начинает кампанию «повержённым», его выручает rescue-телепорт.
- Катсцены и скриптовые сцены синхронизируются частично.
- Поддерживается только Steam-билд с указанным хешем, патчи и оффсеты привязаны к билду.
- Только Windows (игра 32-битная).

## Быстрый старт

Нужны две копии папки с игрой: для хоста и для гостя. Установку Steam не патчьте, работайте с копиями.

1. Запустите `launcher/FoCCoop.exe` и укажите каждую копию игры. Лаунчер проверит хеш exe, поставит
   `dinput8.dll` и создаст `foc_coop.ini`.
2. **Хост:** выберите главу кампании или карту Escalation и нажмите *Host*.
3. **Гость:** введите IP хоста (`127.0.0.1` на одном ПК) и порт `7778`, нажмите *Join*.

Вручную: хост открывает
`ESC_Ark_BASE_m?Game=TransContent.TnSurvivalGame?listen?MaxPlayers=5`, гость подключается к `127.0.0.1:7778`.

## Настройка

Параметры читаются из `foc_coop.ini` рядом с exe игры, секция `[foc_coop]`.

| Ключ | Действие |
|---|---|
| `instance=B` | Суффикс мьютекса единственного экземпляра, чтобы запускать несколько копий на одном ПК |
| `tcpdriver=1` | Использовать `IpDrv.TcpNetDriver` вместо драйвера Demonware |
| `forcechar=1` | Принудительно «персонажи загружены» (чтобы выйти с экрана загрузки Escalation) |
| `maxplayers=N` | Лимит игроков на хосте |
| `tutguard=1`, `skiptut=1` | Защита и патчи туториала, который роняет хоста кампании |
| `ctrlshare=1`, `hostfirst=1` | Общие контроллеры и порядок «хост первым» (кампания) |
| `rescue=1` | Телепорт упавшего персонажа к другому игроку |
| `holdspawn=1`, `spawnafter=N` | Задержка спавна гостя |
| `ctrldiag`, `scan`, `dump`, `trace`, `lp` | Диагностика и эксперименты, пишут дополнительные логи |

Всё пишется в `foc_coop.log` рядом с exe (сетевые вызовы, исключения, регистры и стек при падении).

## Как это работает

Прокси `dinput8.dll` лежит рядом с `TFOC.exe` и загружается вместо системного. Во время работы он:

- находит таблицы имён и объектов движка и нужные классы,
- переключает сетевой драйвер на TCP в загруженных строках конфига,
- поднимает лимит игроков и принудительно ставит `TnLocalPlayer._CharactersLoaded`,
- патчит логику туториала, которая роняет хоста кампании,
- раздаёт и упорядочивает контроллеры игроков, чтобы гость мог заспавниться.

## Сборка

- Прокси-DLL: `build.bat` (Visual Studio 2022 Build Tools, x86). Исходники: `src/proxy_dinput8/`.
- Лаунчер: один C#-файл `launcher/FoCCoop.cs`, компилируется штатным `csc.exe` из .NET Framework в Windows
  (синтаксис C# 5).
- Готовые `launcher/FoCCoop.exe` и `launcher/payload/dinput8.dll` лежат в репозитории.
- `lpdiff.py` и `snapdiff.py` — скрипты для сравнения снимков памяти работающей игры.

## Планы

1. Починить графику гостя и «повержённый» старт.
2. Пройти главы 2-9.
3. Поддержать 3-5 игроков.
4. Игра через интернет (Steam-relay или инструкция по VPN).
5. Установщик.
6. Больше карт Escalation и режимы версуса.
