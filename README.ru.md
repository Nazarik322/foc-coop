# foc-coop — кооператив для Transformers: Fall of Cybertron (DEV / в разработке)

**Языки:** [English](README.md) | **Русский**

Неофициальный слой кооператива для **Transformers: Fall of Cybertron** (Steam app 213120, билд 12831,
`TFOC.exe` SHA-256 `c1dab177f81503ecb831d63a3d799f928dd9823242ca3689482c684396acfedc`).
Кампания одиночная, а официальные онлайн-сервисы мертвы, поэтому кооператив строится поверх
штатной репликации Unreal Engine 3 по обычному TCP (прямой IP).

> **Статус: ранняя dev-версия.** Это proof of concept, а не готовый мод. Возможны вылеты, глюки
> графики и недостающие функции. Файлов игры в репозитории нет, нужна своя копия игры.
> Проект не связан с Hasbro, High Moon Studios и Activision.

## Что работает

- **Escalation на двоих** (проверено на карте Ark) между двумя копиями игры на одном ПК: хост и клиент
  попадают в матч и играют.
- **Кампания, глава 1 (The Exodus), двое игроков**: хост запускает карту, второй игрок заходит по
  прямому IP и загружается. *Rescue-телепорт* возвращает упавшего/застрявшего персонажа к хосту.
- **Сеть по прямому IP** через `IpDrv.TcpNetDriver` (драйвер Demonware отключён).
- **Лаунчер** (`launcher/FoCCoop.exe`, WinForms): ставит прокси-DLL в копию игры и запускает сессию
  хоста или гостя; выбор главы / карты Escalation, число игроков, порт, оконный режим.
- **Несколько копий игры на одном ПК** (`instance=` меняет имя мьютекса единственного экземпляра).

## Что не работает / известные проблемы

- **Графика у гостя**: у клиента часть персонажей — тёмные силуэты / тёмные текстуры.
- **Гость начинает «повержённым»** в кампании, спасает rescue-телепорт.
- **Главы 2–9 не проверены** (есть в списке лаунчера, но могут вылетать или зависать).
- **3–5 игроков не проверено**, подтверждено только 2.
- **Игра через интернет не решена**: только LAN / localhost / VPN с доступным IP. Steam-relay нет.
- Катсцены и скриптовые сцены синхронизируются частично.
- Режимы версуса, кроме Escalation, не пробовались.
- Нет установщика; лаунчеру нужно указать копию игры (он проверяет хеш exe).
- Поддерживается только Steam-билд с указанным SHA-256 (оффсеты и патчи привязаны к билду).
- Только Windows, игра 32-битная.

## Как это работает

`src/proxy_dinput8/dinput8.cpp` собирается в 32-битный прокси `dinput8.dll`, который кладётся рядом с
`TFOC.exe`. Игра загружает его вместо системного, после чего он:
- находит структуры движка (GNames / GObjObjects) и нужные классы во время работы,
- переключает сетевой драйвер на TCP в загруженных строках конфига,
- поднимает лимит игроков, принудительно ставит `TnLocalPlayer._CharactersLoaded`, патчит логику
  туториала, роняющую хоста кампании, и раздаёт/упорядочивает контроллеры, чтобы гость мог заспавниться,
- пишет всё в `foc_coop.log` (сетевые вызовы, исключения, регистры/стек при падении).

Настройки в `foc_coop.ini` рядом с exe, секция `[foc_coop]`:

| ключ | действие |
|---|---|
| `instance=B` | добавляется к имени мьютекса, чтобы запускать несколько копий на одном ПК |
| `tcpdriver=1` | использовать `IpDrv.TcpNetDriver` вместо Demonware |
| `forcechar=1` | принудительно «персонажи загружены» (нужно, чтобы выйти с экрана загрузки Escalation) |
| `maxplayers=N` | лимит игроков на хосте |
| `tutguard`, `skiptut` | защита/патчи туториала, роняющего хоста кампании |
| `ctrlshare`, `hostfirst` | общие контроллеры и порядок «хост первым» (кампания) |
| `rescue=1` | rescue-телепорт упавших персонажей |
| `holdspawn`, `spawnafter` | задержка спавна гостя |
| `ctrldiag`, `scan`, `dump`, `trace`, `lp`, ... | диагностика и эксперименты, пишут дополнительные логи |

## Быстрый старт (2 игрока, один ПК или LAN)

1. Сделайте **две копии** папки с игрой (установку Steam не патчить).
2. Запустите `launcher/FoCCoop.exe`, укажите каждую копию; он поставит `dinput8.dll` и создаст `foc_coop.ini`.
3. Хост: выберите главу (или карту Escalation) и нажмите Host.
   Гость: введите IP хоста (`127.0.0.1` на одном ПК), порт `7778`, нажмите Join.
4. Вручную: хост открывает `ESC_Ark_BASE_m?Game=TransContent.TnSurvivalGame?listen?MaxPlayers=5`,
   гость — `127.0.0.1:7778`.

## Сборка

`build.bat` (Visual Studio 2022 Build Tools, x86) собирает прокси-DLL. Лаунчер — один C#-файл,
компилируется штатным `csc.exe` из .NET Framework в Windows (синтаксис C# 5). Готовые
`launcher/FoCCoop.exe` и `launcher/payload/dinput8.dll` лежат в репозитории для удобства.
`lpdiff.py` / `snapdiff.py` — скрипты для сравнения снимков памяти работающей игры.

## Планы

1. Починить графику гостя и «повержённый» старт. 2. Пройти главы 2–9. 3. 3–5 игроков.
4. Игра через интернет (Steam-relay / инструкция по VPN). 5. Установщик. 6. Больше карт Escalation и версус.

## Отказ от ответственности

Исследование совместимости для личного использования с легально купленной копией игры. Используйте на
свой риск. Не предназначено для работы с официальными онлайн-сервисами.
