ReShade for foc-coop (installed by FoCCoopSetup.exe as an optional extra).

- ReShade 6.8.0 by crosire (https://reshade.me), ReShade32.dll installed as Binaries\d3d9.dll. License: LICENSE_ReShade.txt.
- Preset: "good color preset" by fpc (https://sfx.thelazy.net/games/preset/10924/), Clarity removed (it was at strength 0).
  Only colour/sharpening effects, no depth buffer, so it works the same in online co-op.
- Shaders: AdaptiveSharpen, Colourfulness (bacondither, BSD-2, see the file headers); Vibrance, DPX, Curves, Levels
  (CeeJayDK SweetFX, MIT: LICENSE_SweetFX.txt); ReShade.fxh, ReShadeUI.fxh (CC0).
- In game: Home opens the ReShade menu (effects on/off, settings).
